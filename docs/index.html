浅拷贝后，原列表为什么会变？

哪种写法会改变 a？先猜，再展开结果。

结果来自构建时执行的 Python 代码。

修改内层列表

Python
a = [[1], [2]]
b = a.copy()
b[0].append(99)
print('a =', a)
print('b =', b)
print('a[0] is b[0]:', a[0] is b[0])
查看运行结果
a = [[1, 99], [2]]
b = [[1, 99], [2]]
a[0] is b[0]: True

两个外层列表仍共享第一个内层列表。

替换外层元素

Python
a = [[1], [2]]
b = a.copy()
b[0] = [99]
print('a =', a)
print('b =', b)
print('a[0] is b[0]:', a[0] is b[0])
查看运行结果
a = [[1], [2]]
b = [[99], [2]]
a[0] is b[0]: False

现在 b 的第一个元素指向一个新列表。

你的预测

下一次实验

根据本次预测推荐。

只复制要修改的内层列表

先验证解除内层共享后，同样的 append 还会不会改到 a。

a = [[1], [2]]
b = a.copy()
b[0] = b[0].copy()
b[0].append(99)
print('a =', a)
print('b =', b)
print('a[0] is b[0]:', a[0] is b[0])
查看后续实验结果
a = [[1], [2]]
b = [[1, 99], [2]]
a[0] is b[0]: False

给副本追加一个新元素

再验证一次只修改外层列表时，原列表会不会变化。

a = [[1], [2]]
b = a.copy()
b.append([99])
print('a =', a)
print('b =', b)
print('a[0] is b[0]:', a[0] is b[0])
查看后续实验结果
a = [[1], [2]]
b = [[1], [2], [99]]
a[0] is b[0]: True

把浅拷贝改成直接赋值

你已经区分了两种修改。接着检查没有复制外层列表时，替换元素会发生什么。

a = [[1], [2]]
b = a
b[0] = [99]
print('a =', a)
print('b =', b)
print('a[0] is b[0]:', a[0] is b[0])
查看后续实验结果
a = [[99], [2]]
b = [[99], [2]]
a[0] is b[0]: True
